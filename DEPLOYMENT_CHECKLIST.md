# Deployment checklist

### Public demonstration
- [ ] GitHub Pages source configured to `main` / `/docs` only
- [ ] Demo banner visible on kiosk and staff pages
- [ ] Submit fictitious `202-555-0104` with `name@example.com` (and a made-up name/DOB)
- [ ] Reject an actual-looking phone number in demo mode
- [ ] Staff demo can see the test record and generate `FirstName|PhoneNumber` QR
- [ ] Browser reset restores fictional starter records
- [ ] Fictional email export includes only unique addresses; email status independent of SMS

### Operational version — NOT approved by default
- [ ] Recruiting office / IT / cybersecurity authorize app, records storage and endpoints
- [ ] Privacy notice and consent language approved, including minors
- [ ] Authorized device/browser can read and write locally selected approved CSV
- [ ] Real records are never stored in GitHub, GitHub Issues, public websites or personal accounts
- [ ] QR/iPhone data transfer authorized; use only approved managed devices
- [ ] Staff can confirm actual successful sends; scanning QR alone never means contacted
- [ ] Approved email account, BCC/mail-merge process and email-contact status verified
- [ ] Backup/retention/deletion procedures established
- [ ] No unauthorized USBs, restricted downloads or security bypasses
