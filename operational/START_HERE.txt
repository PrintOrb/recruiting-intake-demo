RECRUITING INTAKE SYSTEM — STANDALONE
=====================================

INDEPENDENT PROTOTYPE — NOT AN OFFICIAL U.S. AIR FORCE APPLICATION.
NOT APPROVED BY DEFAULT FOR REAL STUDENT DATA COLLECTION.

1. Extract the complete GitHub Release ZIP. Do not launch HTML files
   from inside a ZIP archive.

2. Open Recruiting_Intake_Kiosk.html in desktop Edge/Chrome.
   Select the included blank Recruiting_Leads.csv.
   Test with fictional student information first.

3. Open Recruiting_Staff_Manager.html and select that SAME CSV.
   Review records, age/birthdays, SMS QR batches and email outreach.

4. Use Get iPhone Shortcut to open the companion installer. The Apple
   iCloud link requires internet access; inspect the Shortcut actions.
   A QR scan does not automatically update a contact status.
   Confirm only messages actually sent.

5. For email outreach, use an authorized email account and mark
   Emailed only after a confirmed send.

6. To customize the text, photos, theme or Shortcut URL:
      assets/js/Recruiting_Config.js

7. For detailed guidance:
      README.md
      docs/CUSTOMIZATION_GUIDE.md
      docs/TECHNICAL_REFERENCE.md
      docs/TESTING_CHECKLIST.md
      docs/DEPLOYMENT_CHECKLIST.md

SECURITY:
Local records are unencrypted and these pages have no login or server.
Authorization is needed for devices, storage, privacy/consent,
collection from minors and any phone/QR transfer.
Never upload actual leads to GitHub or personal accounts.
